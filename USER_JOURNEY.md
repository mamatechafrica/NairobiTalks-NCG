# NairobiTalks - User Journey Documentation

## Overview
NairobiTalks is a comprehensive citizen engagement platform designed to enhance participatory governance in Nairobi County. This document outlines the complete user journeys for all stakeholder groups, showcasing how the platform bridges the gap between citizens and government.

## Target Audiences
- **Citizens/Residents of Nairobi** - Primary users who engage with civic content
- **County Administrators** - Government officials managing the platform
- **Community Leaders** - Influencers who can amplify civic participation
- **External Stakeholders** - NGOs, development partners, and researchers

---

## 🌟 Citizen User Journey

### **Phase 1: Discovery & Onboarding**

#### **Entry Points**
- **Homepage** (`/`) - Welcoming interface showcasing platform value proposition
- **Landing Page** (`/landing`) - Detailed feature exploration
- **Direct Access** - Through community campaigns, social media, or referrals

#### **Registration Process**
1. **Sign Up** (`/users/sign_up`)
   - Simple email and password registration
   - Terms of service and privacy policy acknowledgment
   - Immediate account creation with email confirmation

2. **Sign In** (`/users/sign_in`)
   - Secure authentication for returning users
   - Password recovery options
   - Remember me functionality for convenience

#### **First-Time User Experience**
- Personalized welcome message
- Quick tour of platform features
- Immediate access to public content (community ideas, planning documents)

---

### **Phase 2: Active Engagement**

#### **Content Discovery**
- **Community Ideas Browser** (`/community_ideas`)
  - Browse trending and recent community proposals
  - Filter by categories, popularity, or date
  - Search functionality for specific topics of interest

- **Planning Documents Viewer** (`/planning_documents`)
  - Access official county planning documents
  - View AI-powered summaries for complex documents
  - Download or bookmark important documents

#### **Participation Actions**

**1. Submit Community Ideas** (`/community_ideas/new`)
- Rich text editor for detailed proposals
- Category tagging for better organization
- Location-based tagging for neighborhood-specific ideas
- Draft saving functionality for longer compositions

**2. Voting & Feedback**
- **Upvote/Downvote System** - Clear visual indicators (✓/✗)
- **Commenting** - Detailed feedback and discussion threads
- **Share** - Social media integration to amplify reach

**3. Submissions & Feedback** (`/submissions`)
- Submit formal feedback on county projects
- Track submission status through personal dashboard
- Receive notifications on response updates

#### **Personal Dashboard** (`/profile`)
- **Submission History** - Track all submitted ideas and feedback
- **Engagement Metrics** - View voting history and comment activity
- **Profile Management** (`/profile/edit`) - Update personal information
- **Notifications** - Stay updated on responses and community activity

---

### **Phase 3: Community Building**

#### **Discussion Forums** (`/topics`)
- Participate in structured discussions on civic matters
- Create new topics for community conversations
- Follow topics of interest for notifications

#### **Ideas Explorer** (`/ideas_explorer`)
- Advanced filtering and discovery tools
- Trending topics analysis
- Interactive data visualization of community engagement

#### **Analytics Access** (`/data/analytics`)
- View public engagement metrics
- Understand community participation patterns
- Access transparent data on platform usage

## 🛡️ Administrator User Journey

### **Phase 1: Secure Access**

- Enhanced security requirements
- Session management and activity logging

#### **Dashboard Overview** (`/admin/dashboard`)
- Real-time platform statistics
- Pending items requiring attention
- Quick access to all management modules

---

### **Phase 2: Content Management**

#### **Community Ideas Management**
- **Review Queue** (`/admin/community_ideas`)
  - Approve/reject submitted ideas
  - Bulk actions for efficient processing
  - Flag inappropriate content for review

- **Content Moderation** (`/admin/community_ideas/show`)
  - Edit and enhance user submissions
  - Add official responses and status updates
  - Archive or feature notable submissions

#### **Planning Documents Administration**
- **Document Management** (`/admin/planning_documents`)
  - Upload and organize official documents
  - Generate AI summaries automatically
  - Control access permissions and visibility

- **Document Creation** (`/admin/planning_documents/new`)
  - Rich document editor with formatting tools
  - Metadata management for better searchability
  - Version control and change tracking

#### **Submissions Processing**
- **Inbox Management** (`/admin/submissions`)
  - Review all citizen submissions
  - Update submission statuses (Under Review, Approved, Rejected)
  - Add internal notes and comments
  - Bulk update capabilities for efficient processing

#### **Community Engagement**

- **Broadcast System** (`/admin/broadcasts`)
